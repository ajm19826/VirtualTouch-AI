# Installation and First Launch

## Install

1. Download `VirtualTouch-AI-Beta-1.5.4-Build-13.dmg`.
2. Open the DMG.
3. Drag `VirtualTouch AI.app` to `Applications`.
4. Open the app from Applications.

macOS may warn that the app has not been notarized. Only continue if this copy came from the release source or an owner you trust.

## First Launch

1. Allow Camera access when prompted.
2. Open the app's Diagnostics page.
3. Grant Accessibility access in System Settings.
4. Enable Camera access in the macOS Privacy settings if it is missing.
5. Start Virtual Touch.

Accessibility is required for cursor movement and mouse events. Camera access is required for finger and pose tracking.
