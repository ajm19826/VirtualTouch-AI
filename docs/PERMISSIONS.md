# Camera and Accessibility Setup

## Camera

The app requests camera access before processing frames. If permission is denied:

1. Open System Settings > Privacy & Security > Camera.
2. Enable VirtualTouch AI.
3. Quit and reopen the app.

If no camera appears, connect an external webcam or verify that another application is not exclusively holding the built-in camera.

## Accessibility

Accessibility permission allows VirtualTouch AI to move the cursor, press mouse buttons, drag, and scroll.

1. Open System Settings > Privacy & Security > Accessibility.
2. Click the lock and authenticate.
3. Enable VirtualTouch AI.
4. Return to the app and use Test cursor movement in Diagnostics.

## Voice Recognition and Microphone

Voice commands are optional. The app requests Speech Recognition and Microphone permission only when voice recognition is enabled.

Supported voice commands:

- Click
- Left
- Stop
